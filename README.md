# Mobile Apps Releases

Official Android APK releases created and maintained by Ashish Ranjan. Use this repository for versioned APK downloads and release notes.

## Download

Browse the catalog and app previews:

[Mobile Apps Distribution](https://a2rp.github.io/mobile-apps-distribution-page/home)

Download published APK files from:

[GitHub Releases](https://github.com/a2rp/mobile-apps-releases/releases)

## Install

1. Download the required APK from GitHub Releases.
2. Open it on your Android device.
3. Allow installation from unknown sources if Android requests permission.
4. Install and launch the app.

Only download files from this repository or the official distribution page. Android may show a security warning for APKs installed outside the Google Play Store.
